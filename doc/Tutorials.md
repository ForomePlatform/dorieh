The **Medicare data warehouse pipeline** — the FTS → YAML → SQL ingestion
pattern, federated views across years, validation and journaling, and
HLL-based quality control — has its own tutorial:
[Building the Medicare Claims Pipeline](tutorial/medicare/building-medicare-pipeline.md).
The reference documentation for the case study is
[Medicare: Building a Data Warehouse from ResDac Files](Medicare.md), and
the operational step-by-step guide is
[Example: Medicare Processing Pipeline](medicare-example.md), which uses
the publicly available synthetic dataset on Zenodo so no data use agreement
is required to follow along. The same material is developed in Chapter 8 of
the companion book
[*Research Data that Can Be Trusted*](about-the-book.md).
